# REU Brief

Type the name of a summer research programme — or a vague half-remembered description of one — and get a one-page brief: whether *you* are eligible (computed in code, with the deciding quote), the problem statement, shared fields with your CV, number of SOPs and recommendation letters, mentors, deadline, and a source link for every claim.

Status: specs written, build in progress. See `SCHEDULE.md` for the plan and `PROGRESS.md` for where things stand.

- Website: `docs/` (GitHub Pages)
